# Problem set 3 — UTXOhunt

[Course record](../README.md) · [Full MIT prompt](https://ocw.mit.edu/courses/mas-s62-cryptocurrency-engineering-and-design-spring-2018/pages/assignments/pset3-utxohunt/) · [Original instructions](https://github.com/mit-dci/mas.s62/tree/master/pset03)

**Status:** Not started.

UTXO means unspent transaction output.
It is an output that a later transaction can spend.

The exercise covers keys, addresses and unspent outputs.
The learner builds and signs transactions.
The exercise also uses an `OP_RETURN` output to store a short message.
That output cannot be spent.
The original Go starter files are in this folder.

Read the full prompt before starting.
The 2018 instructions refer to old libraries and testnet3.
Testnet3 is a separate Bitcoin network used for tests.
The original shared test outputs may no longer be available.
Their status has not been checked.

Before this assignment, prepare a separate test environment and fresh test outputs.
Review the old library paths and commands at that point.
Keep the existing mainnet node configuration unchanged.
The public example key phrases are for the exercise only.
Do not add personal wallet secrets or account details to the code or messages.

No code has been run and no transactions have been sent for this assignment.
